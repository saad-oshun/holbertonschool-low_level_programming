# C - Structures, typedef

Defining structures, using `typedef`, and allocating / freeing structures.

| File | Description |
| --- | --- |
| `dog.h` | Defines `struct dog`, the `dog_t` type, and all prototypes |
| `1-init_dog.c` | Initializes a variable of type `struct dog` |
| `2-print_dog.c` | Prints a `struct dog` (prints `(nil)` for NULL elements) |
| `4-new_dog.c` | Creates a new dog, storing copies of name and owner |
| `5-free_dog.c` | Frees a dog created by `new_dog` |
