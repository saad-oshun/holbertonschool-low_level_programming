# C - More malloc, free

Using `malloc`, `free` and `exit`, and re-implementing `calloc`.

| File | Description |
| --- | --- |
| `main.h` | Header file with all prototypes |
| `0-malloc_checked.c` | Allocates memory; exits with status 98 if malloc fails |
| `1-string_nconcat.c` | Concatenates s1 with the first n bytes of s2 |
| `2-calloc.c` | Allocates zeroed memory for an array (like calloc) |
| `3-array_range.c` | Creates an array of integers from min to max |
