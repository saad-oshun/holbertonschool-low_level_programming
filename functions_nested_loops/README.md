# C - Functions, nested loops

Holberton School project about functions, prototypes, header files and nested loops in C.

| File | Description |
|---|---|
| `main.h` | Header file with all prototypes |
| `0-putchar.c` | Prints `_putchar` |
| `1-alphabet.c` | Prints the alphabet in lowercase |
| `2-print_alphabet_x10.c` | Prints the alphabet 10 times |
| `3-islower.c` | Checks for a lowercase character |
| `4-isalpha.c` | Checks for an alphabetic character |
| `5-sign.c` | Prints the sign of a number |
| `6-abs.c` | Computes the absolute value of an integer |
| `7-print_last_digit.c` | Prints the last digit of a number |
| `8-24_hours.c` | Prints every minute of the day from 00:00 to 23:59 |
| `9-times_table.c` | Prints the 9 times table |
| `10-add.c` | Adds two integers |
| `11-print_to_98.c` | Prints all integers from n to 98 |
